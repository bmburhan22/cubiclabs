# Dashboard Screenshot

## Current Screenshot
The MacBook scroll component currently displays `dashboard-screenshot.svg`, which is a placeholder.

## How to Replace with Your Own Screenshot

### Option 1: Use an Actual Screenshot
1. Take a screenshot of your actual website/dashboard
2. Save it as `dashboard-screenshot.png` or `dashboard-screenshot.jpg`
3. Place it in this directory (`public/images/`)
4. Update the src in `app/page.tsx` from `.svg` to `.png` or `.jpg`

### Option 2: Use a Design Tool
1. Create your design in Figma, Photoshop, or similar
2. Export as PNG (recommended size: 1920x1080 or 2560x1440)
3. Save as `dashboard-screenshot.png`
4. Place in this directory

### Option 3: Customize the SVG
The current `dashboard-screenshot.svg` can be edited:
- Open in any text editor
- Modify colors, text, layout
- Change gradients to match your brand
- Add your actual UI elements

## Recommended Specifications
- **Format**: PNG or JPG (SVG works but limited)
- **Dimensions**: 1920x1080 (16:9 aspect ratio)
- **File Size**: Under 2MB for best performance
- **Content**: Your actual dashboard, app interface, or product preview

## Tips for Best Results
- Use high-quality screenshots with clear text
- Ensure good contrast for readability
- Show your best features prominently
- Consider using a screenshot with your brand colors
- Test on mobile to ensure it looks good when scaled
